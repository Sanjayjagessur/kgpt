# Unit 1: Integers

Integers are whole numbers that can be positive, negative or zero. On a number line, numbers to the right are greater. For example, -2 is greater than -5.

When adding integers with different signs, subtract the smaller absolute value from the larger and keep the sign of the number with the larger absolute value: -7 + 3 = -4.

# Unit 4: Simple equations

A linear equation such as 3x - 7 = 11 is solved by doing the same operation to both sides. Add 7 to both sides to get 3x = 18, then divide both sides by 3 to get x = 6. Always check by substituting: 3(6) - 7 = 11.
